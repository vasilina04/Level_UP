# Проверки LEVEL UP

Проверки доработки от 22 ноября 2026 выполнялись на Windows с PostgreSQL и Chrome на production-сборке Next.js. Новая отдельная база получила все восемь миграций и вымышленные данные. Сквозные тесты изменяли только тестовую базу.

| Проверка | Результат |
| --- | --- |
| `pnpm typecheck` | Успешно |
| `pnpm build` | Сборка и запуск Next.js прошли |
| `pnpm test` | 30 модульных тестов; на Windows `--configLoader runner` обходит ограничение чтения родительских каталогов esbuild |
| `pnpm test:e2e` | 47 сценариев в Chrome; полный повторный прогон после исправлений |
| `pnpm exec prisma migrate status` | Схема локального демо актуальна |

Проверяются сохранение результата дисциплины и оценки, одно событие XP, повтор одинакового запроса, запрет второй ожидающей отправки, поддержка старой формы отправки и отказ чужому студенту/преподавателю. |

Снимки снимаются при заданной `AUDIT_EVIDENCE_DIR`: PNG и JPG на 360, 390, 768 и 1440 px. Матрица HTTP, горизонтальной прокрутки и ошибок браузера охватывает также 375, 430 и 1024 px. axe проверяет выбранные страницы и новые формы проверки работ. Снимки, локальные базы и секреты в Git не включаются.

В этой доработке устранены переполнение карточки плана дисциплины длинными статусами и запрет ответа преподавателя на отправленную работу без вопроса. В сборке после изменений CSS проверено обновление стилей; при устаревшем webpack-кэше потребовалась его очистка.

В первом прогоне выявились гонка между созданием напоминания и чтением списка уведомлений, а также расхождение видимой подписи и доступного имени в календаре. Проверки повторены после изменений. Автоматический аудит охватывает проверяемые правила axe, а проверку настоящим скринридером и доставку внешних уведомлений следует проводить после развёртывания.

## Воспроизведение

Укажите в PowerShell `DATABASE_URL` отдельной тестовой базы, созданной по инструкции в README, и запустите команды:

```powershell
$env:ENABLE_DEMO_SEED = '1'
pnpm db:generate
pnpm db:deploy
pnpm db:seed
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

Для проверки сборки через `pnpm start --hostname 127.0.0.1 --port 3011` задайте `AUTH_LOCAL_HTTP=1` и `AUTH_URL=http://127.0.0.1:3011` в терминале сервера. В терминале тестов задайте `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3011` и тот же `DATABASE_URL`. В `PLAYWRIGHT_CHROMIUM_EXECUTABLE` можно указать путь к уже установленному Chrome.
