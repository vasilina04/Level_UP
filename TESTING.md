# Проверки LEVEL UP

Проверки выполнялись на Windows с PostgreSQL 15, Node.js 24 и Chrome. Новый экземпляр базы получил все шесть миграций и вымышленные данные. Сквозные тесты использовали отдельную базу, чтобы тестовые записи не попали в пользовательский кабинет.

| Проверка | Результат |
| --- | --- |
| `pnpm typecheck` | Успешно |
| `pnpm build` | Сборка и запуск Next.js прошли |
| `pnpm test` | 22 из 22 модульных тестов |
| `pnpm test:e2e` | 33 из 33 сценариев в Chrome, включая 4 сценария новых разделов |
| `pnpm exec prisma migrate status` | Схема локального демо актуальна |

## Сценарии

| Сценарий | Что проверяется |

| Консультации | Запись из карточки, гонка двух запросов за один слот, подтверждение преподавателем, предложение альтернативы, принятие студентом, уведомления и календарь. |
| Рейтинг и публикация | Сохранение черновика, отказ записи в опубликованную версию на уровне PostgreSQL, новая версия после переноса, различия и уведомления. Прогноз 15 × 2 даёт 30 баллов в браузере без записи результата. Публикация обновляет рейтинг, итоговую оценку и после отдельного подтверждения сдачи начисляет 70 XP. |
| Календарь | Личная отметка и напоминание переживают перезагрузку, дата меняется после переноса, дополнительная активность появляется после согласования и пропадает после отказа студента. После переноса на завтра отображается одно напоминание, даже когда мероприятие связано с квестом. |

Сервер отклоняет запрос с другого Origin и изменение оценки от имени студента или неназначенного преподавателя. В прежних сценариях отдельно проверяются заявки и переписка. |

В первом прогоне выявились гонка между созданием напоминания и чтением списка уведомлений, а также расхождение видимой подписи и доступного имени в календаре. Проверки повторены после изменений. Автоматический аудит охватывает проверяемые правила axe, а проверку настоящим скринридером и доставку внешних уведомлений следует проводить после развёртывания.

## Воспроизведение

Укажите в PowerShell `DATABASE_URL` отдельной тестовой базы, созданной по инструкции в README, и запустите команды:

```powershell
$env:ENABLE_DEMO_SEED = '1'
pnpm db:generate
pnpm db:deploy
pnpm db:seed
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

Для проверки сборки через `pnpm start --hostname 127.0.0.1 --port 3011` задайте `AUTH_LOCAL_HTTP=1` и `AUTH_URL=http://127.0.0.1:3011` в терминале сервера. В терминале тестов задайте `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3011` и тот же `DATABASE_URL`. В `PLAYWRIGHT_CHROMIUM_EXECUTABLE` можно указать путь к уже установленному Chrome.
